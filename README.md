# Inject Synthesizer

A Jekyll-based static website for the Inject Synthesizer project.

## 🌐 Live Preview

**Local Development**: http://localhost:3000

**GitHub Pages**: Coming soon (deploy to GitHub Pages to get your live URL)

## 📋 Prerequisites

- Ruby 3.2 or higher
- Bundler

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/rigvida04/Inject_synthesizer.git
cd Inject_synthesizer
```

2. Install dependencies:
```bash
bundle config set --local path 'vendor/bundle'
bundle install
```

### Running the Website

Start the development server:
```bash
bundle exec jekyll serve --host 0.0.0.0 --port 3000
```

The website will be available locally at http://localhost:3000
