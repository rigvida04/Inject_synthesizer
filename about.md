# About Inject Synthesizer

This is the about page for the Inject Synthesizer project.

## What is Inject Synthesizer?

Inject Synthesizer is a web-based project designed to showcase modern web development practices using Jekyll and GitHub Pages.

## Technology Stack

- Jekyll static site generator
- Markdown for content
- GitHub Pages for hosting
- Minima theme for styling
